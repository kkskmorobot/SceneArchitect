# SceneArchitect 前端启动

## Windows 双击启动

双击本文件夹中的 `start.bat`。它会自动使用项目根目录的 `.venv`，并打开 `http://127.0.0.1:7860`。

## PyCharm 启动

1. 在 PyCharm 中打开 `BuShu/start.py`。
2. 右键选择“运行 start”。
3. 如果提示缺少依赖，把运行配置的 Python 解释器改成项目根目录 `.venv/Scripts/python.exe`。

生成结果位于 `BuShu/output/<本次生成 ID>/`。每次生成会保存图片、`metadata.json`，使用草稿时还会保存 `control.png`。

## Depth ControlNet 断点下载

如果 Depth 权重尚未下载完成，请在项目根目录打开 PowerShell 7，运行：

```powershell
pwsh -ExecutionPolicy Bypass -File ".\BuShu\download_depth_controlnet.ps1"
```

网络中断或窗口超时后，重新运行同一条命令即可。脚本不会删除 `.part`，完整下载后会自动检查文件大小和 SHA-256。

## 完整版 SDXL Canny ControlNet

前端中的 `canny`、`depth` 是 Small 版本，`canny-full` 是完整尺寸的官方 SDXL Canny ControlNet。下载命令：

```powershell
pwsh -ExecutionPolicy Bypass -File ".\BuShu\download_full_canny_controlnet.ps1"
```

脚本会下载到 `%USERPROFILE%\Downloads\controlnet-canny-sdxl-1.0`。完成后，把以下两个文件复制到项目的 `models\controlnet-canny-sdxl-1.0\`：

- `config.json`
- `diffusion_pytorch_model.fp16.safetensors`

权重大小必须是 `2502139136` 字节，SHA-256 必须是 `b2e7d3921058a442cc80430d1ec8847f42599c705e2451c95e77cf4dcf8d6c25`。
